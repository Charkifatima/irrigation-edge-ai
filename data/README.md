# Données

- `raw/` : données sources locales, non versionnées.
- `processed/` : données préparées locales, non versionnées.
- Documenter ici la provenance, la licence, les unités et le schéma lorsqu’un jeu de données sera choisi.
- Ne pas déposer de données personnelles ou de secrets. Les petits jeux de test synthétiques pourront être versionnés dans `tests/fixtures/`.

Aucun jeu de données n’est livré par TMGROUP-9.
